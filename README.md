# Тайный Санта: архитектура

**Выполнили:** Клефас Мария, Лоботова Алиса, Тхамоков Анзор, группа ТРПО23-1.

Сервис для игры в Тайного Санту с реальной доставкой подарков. Друзья или коллеги собираются в группу, система проводит жеребьевку, каждый Санта выбирает подарок своему подопечному из каталога маркетплейса и оплачивает его, а маркетплейс доставляет подарок по адресу подопечного. Санта не знает адреса, подопечный не знает, кто его Санта.

## Почему это не один сервис

В системе есть то, что нельзя потерять или задвоить:

- **деньги**: двойное списание, списание без заказа, забытый холд;
- **заказ подарка**: два заказа на маркетплейсе из-за повторного запроса;
- **пары жеребьевки**: у каждого ровно один Санта и ровно один подопечный.

И есть процесс, который может сломаться посередине: заказ подарка проходит через платежного провайдера, наш сервис участников и маркетплейс. Любой из них может упасть между шагами. Платежная часть требует строгой надежности, внешние системы ненадежны, уведомления не должны тормозить заказ, а адреса участников нельзя показывать Санте. Поэтому система разделена на сервисы с отдельными базами.

## Как работает система

1. Организатор создает группу: название, бюджет подарка, дедлайны.
2. Участники вступают по ссылке с кодом приглашения и указывают адрес доставки.
3. Организатор закрывает регистрацию, и система проводит жеребьевку: пары образуют одно кольцо, себе дарить нельзя.
4. Санта выбирает подарок в пределах бюджета.
5. Деньги на карте Санты замораживаются, заказ оформляется на маркетплейсе с адресом подопечного, после подтверждения деньги списываются.
6. Подопечный получает уведомление, что к нему едет подарок, но не знает от кого.
